# community-engagement-sdg11-analysis
This repository contains the analysis code used in the study “Community engagement enables target integration in SDG 11 governance in Japan.”

## Repository structure

- `code/`: Python and R analysis scripts
- `data/`: source data or data-access instructions
- `figures/`: generated figures

## Requirements

Python packages:

- pandas
- numpy
- matplotlib
- openpyxl
- adjustText

R packages:

- readxl
- circlize

## Usage

Place the input dataset at:

`data/Source Data.xlsx`

Run the scripts from the repository root. Generated outputs will be
saved in the `results/` directory.
